# pkg/yaml

Преобразование Lua-таблиц в YAML и обратно. Модуль встроен в Go-рантайм DamuBPM (пакет `pkgyaml`, `gopkg.in/yaml.v3` + `goluago/util`), в `luas` его нет.

2 функции

**Инициализация:** `local yaml = require("pkg/yaml")`

Обе функции при ошибке вызывают Lua error — для своей обработки вызывать через `pcall`.

Поведение ниже проверено запуском исходника `yaml.go` на go-lua.

### marshal

Сериализует Lua-таблицу в YAML (отступ 2 пробела, в конце `\n`).

    text = yaml.marshal(value)

#### Входные параметры

| Параметр | Тип        | Описание                                                                 |
|----------|------------|--------------------------------------------------------------------------|
| value    | table\|nil | Lua-таблица или явный nil. Обязательный аргумент: без него, строка или число → ошибка `need a table at index 1, got ...` |

#### Результирующие параметры

| №   | Значение | Тип    | Описание                                         |
|-----|----------|--------|--------------------------------------------------|
| 1   | text     | string | YAML; для nil — `null\n`; при ошибке Lua error   |

#### Правила преобразования

| Lua                                       | YAML                                                                 |
|-------------------------------------------|----------------------------------------------------------------------|
| таблица со строковыми ключами             | mapping, ключи отсортированы с учётом чисел (`"2"` раньше `"10"`)     |
| `array({...})`                            | список                                                               |
| обычная `{"a","b"}`, `{[1]="a"}`, `{[10]="a"}` | **ошибка** `invalid key to 'next'`                              |
| `array` со строковым ключом               | ошибка `pull array: expected numeric index, got 'string'`            |
| дыра в `array` (`a[1]`, `a[3]`)           | `null` на месте пропуска                                              |
| `{}`                                      | `{}`                                                                 |
| `array({})`                               | `[]`                                                                 |
| `"true"`, `"001"`, `"yes"`, `"null"`, `""` | в кавычках — остаются строками                                      |
| число, \|x\| < 1e6 и ≥ 1e-4               | как есть: `100`, `12.5`, `123456`                                    |
| число, \|x\| ≥ 1e6 или < 1e-4             | **экспонента**: `1000000` → `1e+06`, `1234567` → `1.234567e+06`, `20240115` → `2.0240115e+07` |
| строка с `\n` или `\r`                    | блок `\|` / `\|-` (`\|2-`, если первая строка начинается с пробела)   |
| function, userdata                        | ошибка `pull table, unsupported type function`                       |

У многострочных строк меняется содержимое: `\r\n` и `\r` → `\n`, пробелы в конце каждой строки удаляются (табы остаются). Это касается и ключей. Кириллица и казахские буквы выводятся без экранирования.

Экспонента читается обратно через `yaml.unmarshal` правильно (`1e+06` → 1000000). Проблема только для внешних потребителей, которым нужно целое (GitLab CI, Kubernetes, сторонние парсеры). Варианты: передать строкой `string.format("%d", n)` (получится `"1000000"` в кавычках) или доработать Go (см. «Доработка marshal»).

#### Примеры вызова и вывод значений результата

**Пример 1**

    local s = yaml.marshal({id=501, state="NEW", price=12.5, active=true})
    print("s =", s)
    -- active: true
    -- id: 501
    -- price: 12.5
    -- state: NEW

**Пример 2** — списки только через `array()`

    local s = yaml.marshal({
      user = {name="Ayan", roles=array({"admin","user"})},
      items = array({{sku="A1", qty=2}, {sku="B2", qty=1}}),
      empty = array({})
    })
    print("s =", s)
    -- empty: []
    -- items:
    --   - qty: 2
    --     sku: A1
    --   - qty: 1
    --     sku: B2
    -- user:
    --   name: Ayan
    --   roles:
    --     - admin
    --     - user

**Пример 3** — многострочный текст и большие числа

    local s = yaml.marshal({note="Привет  \r\nмир", total=1500000, code=string.format("%d", 1500000)})
    print("s =", s)
    -- code: "1500000"
    -- note: |-
    --   Привет
    --   мир
    -- total: 1.5e+06

### unmarshal

Разбирает YAML-строку в Lua-значение.

    value = yaml.unmarshal(text)

#### Входные параметры

| Параметр | Тип    | Описание                                                        |
|----------|--------|-----------------------------------------------------------------|
| text     | string | YAML. Число приводится к строке; nil → `bad argument #1 ... (string expected, got nil)` |

#### Результирующие параметры

| №   | Значение | Тип | Описание                                                        |
|-----|----------|-----|-----------------------------------------------------------------|
| 1   | value    | any | table / string / number / boolean / nil; при ошибке Lua error   |

#### Правила преобразования

| YAML                                        | Lua                                                              |
|---------------------------------------------|------------------------------------------------------------------|
| mapping                                     | таблица со строковыми ключами                                    |
| sequence                                    | таблица с меткой `array()` — повторный `marshal`/`JsonToString` дают список, `[]` остаётся `[]` |
| `42`, `0x1F`, `0o17`, `1.0`, `1e3`          | number: 42, 31, 15, 1, 1000                                      |
| целое вне ±9007199254740991                 | ошибка `integer ... exceeds JSON/Lua safe integer range; store it as string` |
| `.nan`, `.inf`                              | ошибка `YAML number NaN is not JSON compatible`                  |
| `true`, `True`, `FALSE`                     | boolean                                                          |
| `yes`, `no`, `on`, `off`                    | string (YAML 1.2)                                                |
| `0123`, `050101300123` (ведущий ноль)        | **восьмеричное** number: 83, 5385846867                          |
| `"001"`, `"050101300123"`                   | string                                                           |
| `null`, `~`, пустое значение                | nil: ключ пропадает из таблицы, в списке — дыра (`#` ненадёжен)   |
| `2024-01-15`                                | string `"2024-01-15T00:00:00Z"`                                  |
| `2024-01-15T10:00:00+05:00`                 | string `"2024-01-15T10:00:00+05:00"` (RFC3339Nano, смещение сохраняется) |
| `!!binary aGVsbG8=`                         | декодированная строка `"hello"`                                  |
| `&anchor`, `*alias`, `<<: *base`            | разворачиваются                                                  |
| ключ не строка: `1: a`, `true: x`, `~: x`   | ошибка `YAML object key must be string for JSON compatibility, got int` |
| несколько документов `---`                  | берётся только первый                                            |
| пустая строка                               | nil                                                              |

Дату в исходном виде (`2024-01-15`) получить можно только взяв значение в кавычки. Комментарии теряются. `\r\n` в тексте допустим. Табы в отступах — ошибка `yaml: line N: found character that cannot start any token`.

Ошибки внутри вложенных объектов получают путь по ключам через `: ` (индексы списков в путь не попадают): `cfg: ports: YAML object key must be string ...`. Синтаксические ошибки: `yaml: line N: ...`.

#### Примеры вызова и вывод значений результата

**Пример 1**

    local v = yaml.unmarshal("id: 501\nstate: NEW\ntags: [a, b]\n")
    print("v =", v)
    print(v.id, v.state, v.tags[1], #v.tags)
    -- 501  NEW  a  2

**Пример 2** — с обработкой ошибки

    local ok, v = pcall(yaml.unmarshal, payload)
    if not ok then
      return {success=false, error="Неверный YAML: " .. tostring(v)}
    end
    if type(v) ~= "table" then
      return {success=false, error="Ожидался объект YAML"}
    end

**Пример 3** — YAML → JSON

    local v = yaml.unmarshal("items:\n  - a\n  - b\nempty: []\n")
    print(JsonToString(v))
    -- массивы уже помечены array(), поэтому выводятся как [...]

## Частые ошибки

1. Обычная Lua-таблица-массив в `marshal` → `invalid key to 'next'`. Каждый список — `array({...})`, включая вложенные. Данные из `yaml.unmarshal` уже помечены и проходят повторный `marshal` без доработки.
2. Целые ≥ 1 000 000 выводятся в экспоненте (`1e+06`). Для внешних систем — `string.format("%d", n)` или доработка Go.
3. Число с ведущим нулём без кавычек читается как восьмеричное: `iin: 050101300123` → 5385846867. ИИН, БИН, коды, номера счетов в YAML — только в кавычках. `marshal` строки сам берёт в кавычки, опасен ручной или внешний YAML.
4. Целые вне ±2^53−1 в YAML-входе — ошибка. Такие значения (64-битные id) хранить строкой в кавычках.
5. `null` в YAML = отсутствие ключа в Lua. Проверять `v.field == nil`, а не наличие ключа.
6. Даты превращаются в RFC3339-строку с временем. Если нужна дата как в файле — кавычки.
7. `marshal` меняет многострочные строки (`\r` и хвостовые пробелы). Для побайтного переноса текста (скрипты, шаблоны) сравнивать после нормализации или передавать base64.
8. `yes`/`no`/`on`/`off` — строки, а не boolean.
9. Не-строковые ключи (`80: http`) — ошибка. Брать в кавычки: `"80": http`.
10. Читается только первый документ из потока `---`.
11. `yaml.marshal()` без аргумента — ошибка; для пустого результата передавать `nil` явно (`null`) или `{}`.

## Доработка marshal (Go, предложение)

Целые Lua-числа выводить без экспоненты: перед `node.Encode(value)` в `marshal` вызвать `value = normalizeLuaNumbers(value)`.

    func normalizeLuaNumbers(value interface{}) interface{} {
    	switch v := value.(type) {
    	case float64:
    		if v == math.Trunc(v) && math.Abs(v) <= 9007199254740991 {
    			return int64(v)
    		}
    		return v
    	case []interface{}:
    		for i := range v {
    			v[i] = normalizeLuaNumbers(v[i])
    		}
    		return v
    	case map[string]interface{}:
    		for k := range v {
    			v[k] = normalizeLuaNumbers(v[k])
    		}
    		return v
    	}
    	return value
    }

Проверено: `1000000` → `1000000`, `20240115` → `20240115`, `1e15` → `1000000000000000`, дроби (`12.5`, `1.2e-05`) и числа вне 2^53 не меняются, остальные тесты дают тот же результат.
